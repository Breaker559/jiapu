## 实测发现并修正

- 表单复杂标签影响辅助工具定位：输入框补充明确可访问名称。
- 手机首页标题被按钮挤压：改为标题与操作上下布局。
- 首页关系预览原先依赖人员排序：改为只展示一位家人与其已保存的子女关系，并在同一 SVG 坐标系内绘制卡片和连线。
- 一张合照给多个人裁剪头像会互相覆盖：改为按人物保存裁剪信息，迁移时重映射并重建。
- 婚恋线原先从卡片底部连向顶部：改为命名的侧面连接点；复杂关系保留独立记录，不把共同育儿归为伴侣；旧版关系标为待细分而不直接修改用户资料。
- 手机全图自动缩放导致文字过小：初始布局设置可读缩放下限，保留手动缩放和平移、全图按钮。
- Python 原先借用了全局环境包：改为独立虚拟环境，锁定本次实测的直接依赖版本。
