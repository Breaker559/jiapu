Family Chart 当前公开数据格式说明以 parents / spouses / children 建模，parents 声明支持一到两人，gender 要求 M/F。家谱已有多种父母关系并存、共同育儿与待核实记录，因此这次借鉴它的展示方式，没有将现有数据直接改写成它的数据模型，也没有导入其源码或新增该依赖。

## 实现边界

- 新增家庭树视图；原逐条关系线保留在“关系明细”中。
- 只有父母编号、关系类型、核实状态完全相同的子女才共用一个分支。不同父母组合和不同类型分别保存、分别展示。
- 已记录且能直接连接的双人关系可作为子女主干的连接位置；没有双人关系记录时，从父母卡片底部接入中性的亲子汇线，不生成配偶记录。
- “显示称谓”默认开启：孩子分支显示子、女、养子、养女等，父母与孩子详情按方向显示父 → 子、母 → 女；性别未注明时采用中性个人称谓。双人关系详情显示“夫妻”或“曾为夫妻”；图谱按每户家庭显示有方向的夫/妻、前夫/前妻，分别支持统一自定义。关系性质在详情和录入表单中单独记录，不作为普通人物称谓。
- 点击汇总连线可查看并进入每一条原始关系，所有来源、备注和核实状态保留。复杂家庭不会被汇总为一条数据库记录。
- 多次关系的人物在组内尽量靠近对方，子女组根据实际父母位置排序；交叉处用留白区分，避免误读成连接点。自由拖动仍可能让线交叉，可重新整理；此版不保证任意规模图谱完全无交叉。
- 新增按家族保存的称谓字典，不改写人物性别或真实关系类型。一次保存多项后，图谱、档案、查询、首页及录入预览统一使用新叫法；设置有所有者权限、版本冲突校验并随备份迁移。
- 按最终确认的每户家庭视角，父母向下连接本组孩子；同一人物在上一户为子/女，在下一户为父/母。婚姻称谓跟随各自家庭分支和记录方向，不设置全图主角。左侧共用世代标尺，人物卡片显示性别、生卒与年龄；悬停可切换资料、照片、生平。

## 验证

- TypeScript / Vite 构建通过。
- 21 项图谱与称谓测试通过，覆盖分组、不同父母组合、类型与核实状态隔离、三位以上父母、无婚姻推断、拖动追踪、单人/空族谱、双向称谓、未注明性别、自定义称谓与派生覆盖、家庭方向及拖动后的箭头方向、共享分支箭头、世代标尺。
- 浏览器验证子/女分支称谓、家庭分组详情完整、称谓开关、关系明细端点、旧关系编辑、共同育儿、移动端、深色模式，以及批量修改称谓后的图谱/档案/查询/首页更新、刷新保留和恢复默认；没有前端运行错误。
