# 家谱实现记录

产品：面向多个家族的现代族谱、相册与家族档案应用。首页的任务是找到人物、进入关系图、补充资料。

视觉方案：云白 #F5F8FA、深墨 #20363C、松绿 #167D73、灰蓝 #7C9098、边线 #E1E9EA、暖杏 #D99C76。中文使用 Microsoft YaHei / PingFang SC，标题配 Segoe UI 的细致字距，数字使用等宽系统字体。字体全部本地回退，不依赖在线 CDN。

布局：窄侧栏承载家族导航；顶部工具条；首页左侧是简洁家族介绍，右侧是一位家人与其已记录子女的关系预览。家族关系图是标志性元素，以连线和人物身份传达结构，不用古书装饰。其余区域通过留白和轻分隔组织。

复核：删除通用营销统计大屏和仿古纹理，以实际家族成员、待核对资料、生日与相册状态替代。手机切换为顶部导航和单栏内容。

运行方式：FastAPI 同源提供 API 与打包后的 React 页面。本地默认 SQLite，服务器可配置 PostgreSQL；两者使用同一套 SQLAlchemy 模型与迁移包。采用 SQLite 是为在当前没有 Docker 的 Windows 环境直接运行，服务器部署提供 PostgreSQL Compose 配置。此变更需要同时验证两种数据库，未验证的环境应在交付中明确标注。

首版重点：真实持久化、登录会话、家族成员角色、人物和关系、原图/缩略图、双历、纪念日、来源、提报审核、修改历史、回收站、家族备份恢复、现代打印。专业 GEDCOM 无损交换、后台定时备份、MFA、收费运营与大型谱书排版须单独跟踪完成情况。
